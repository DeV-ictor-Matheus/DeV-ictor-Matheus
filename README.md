##  Projetos em destaque

###  [Festival CampoAgro 2026](https://github.com/DeV-ictor-Matheus/CAMPOAGRO)
Site institucional do maior festival de agronegócio da região. Migração completa de HTML/CSS para **Next.js 14 + TypeScript**, com funcionalidades comerciais reais:
- Integração com **WhatsApp Business API** para notificação automática de leads
- Sistema de exportação de leads em planilha
- Painel de analytics para apresentação a patrocinadores
- Interface responsiva com foco em performance e UX

`Next.js` `TypeScript` `React` `Node.js` `API REST` `WhatsApp Business API`
